Download Vortex

Get the client to play, or start building in Studio.

Windows

Download Client
  1. Run the installer. If SmartScreen blocks it, click More info then Run anyway.
  2. If Defender flags it after install, go to Windows Security > Virus & threat protection > Protection history and click Allow.

macOS

Download Client
  1. Move Vortex.app (or Vortex Studio.app) to your Applications folder.
  2. Open Terminal and run:
sudo xattr -r -d com.apple.quarantine /Applications/Vortex.app
